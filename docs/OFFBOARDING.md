# Offboarding — 3kings

What the client receives when the engagement ends (per the Moxie agreement), and what RC removes.

## Client receives
- [ ] Full site export (files + database) or migration to their host
- [ ] Brand and media assets from Drive `Clients/3kings`
- [ ] Domain/DNS handover notes (they own the domain)
- [ ] List of licenses that stop with RC (agency plugin licenses)

## RC removes or archives
- [ ] Kinsta site · Cloudflare workers `3kings-*` · Postmark server `3kings` · DO Spaces prefix
- [ ] Contractor access (Bitwarden → Kinsta → Drive → GitHub)
- [ ] Archive GitHub repo; move Drive folder to `Archive/Clients/`; archive Bitwarden collection
- [ ] Mark offboarded in `~/redefined-os/clients/index.md` and Moxie
